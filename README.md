# Outgunned Character Builder API

An OpenAPI-based API for Game Masters and Players of the Director's Cut system (by Two Little Mice), specifically featuring tools for the Outgunned universe.

## Overview

This API provides a suite of tools to enhance your Outgunned tabletop experience, whether you're playing:
- Outgunned
- Outgunned Adventures
- Outgunned Superheroes

As well as supplemental content from:
- World of Killers
- Action Flicks Vol 1
- Action Flicks Vol 2
- Action Flicks Vol 3

## Features

### System Agnostic Tools
- Random NPC generation
- Name generators
- Occupation generators
- Physical description generators

### Outgunned Specific Tools
- Randomized Character Generation
- Character Wizard (planned)
- Specialized tools for the Outgunned Universe (in development)

## Documentation

API documentation is available through the OpenAPI interface at `/openapi.json` when the service is running.
